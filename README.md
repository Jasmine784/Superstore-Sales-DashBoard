# Superstore-Sales-DashBoard


Project Overview:This project is an Excel-based Superstore Sales Dashboard created to analyze sales performance and present important business information through interactive Pivot Tables and charts.
The dashboard provides a visual overview of sales performance across different product categories, regions, and years. It also includes key performance indicators such as total sales, total orders, and unique customers.

Objective: The main objectives of this project are to:
* Clean and analyze the provided Superstore Sales dataset.
* Calculate important sales KPIs.
* Analyze sales performance across different product categories.
* Compare sales performance across different regions.
* Identify sales trends over time.
* Use Pivot Tables and Charts to create an interactive dashboard.

Tools Used:
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas

Key KPIs:
* Total Sales: 2,261,537
* Total Orders: 9,800
* Unique Customers: 793

Dashboard Analysis:
The dashboard provides visual analysis of:
* Sales by Category – compares sales across Technology, Furniture, and Office Supplies.
* Sales by Region – compares sales across Central, East, South, and West regions.
* Sales Over Time – shows how sales changed from 2015 to 2018.
* Unique Customers – shows the number of distinct customers in the dataset.

Key Insights:
* Technology generated the highest sales among the three product categories shown.
* West contributed the largest share of sales among the four regions.
* South contributed the lowest share of sales among the four regions.
* Sales showed an overall upward trend from 2016 to 2018, with a significant increase in 2017 and 2018.
* The dashboard contains 793 unique customers across the dataset.
* The total recorded sales amount is 2,261,537, with 9,800 total orders.

Project Outcome:
This project demonstrates the use of Microsoft Excel for data analysis, Pivot Tables, data visualization, and dashboard creation. The dashboard provides a clear and easy-to-understand view of Superstore sales performance and helps users identify important trends and patterns.
